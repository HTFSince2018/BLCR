# Results provenance for BLCR

This file records the exact completed experiment summaries used in `BLCR.tex`. It is not part of the paper body.

## MinAtar, 2M frames, five seeds

Original artifact: `logs_minatar_neurocomputing_2m/_launcher/minatar_2m_aggregate_summary.csv`

- BLCR exceeds ReLo on all five evaluated games. The completed runs used the historical key `relo_floor_wloss`; the public, numerically equivalent key is `blcr`.
- BLCR has the highest last-100 return among the compared methods on Asterix (`17.894`) and Breakout (`10.594`).
- PER values are preserved exactly as produced by the completed baseline experiments.

## ALE-RAM, 30 games, 2M frames, five seeds

Original artifact: `logs_ale_ram_30games_relo_vs_wloss/_launcher/final_summary_by_task_last100.csv`. The public queue writes new runs under `logs_ale_ram_30games`.

- BLCR exceeds ReLo on 25 of 30 games.
- BLCR wins 118 of 150 paired-seed comparisons under last-100 evaluation.
- This experiment compares BLCR with ReLo, not with PER or uniform replay.

## Gymnasium classic control, 1M steps, three seeds

Original artifact: `logs_gym_1m_baselines_relo_ours`. The public queue writes new runs under `logs_gym_classic_control_1m`.

- All four tasks and all four methods use the same final-100-episode aggregation.

No baseline value has been manually lowered, rescaled, or selectively replaced. Any later change to a reported score should be traceable to a documented evaluation rule applied identically to every method.
